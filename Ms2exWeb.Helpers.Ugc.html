    Ms2exWeb.Helpers.Ugc (MS2EX v0.1.0)

    Copy Markdown View Source

    Shared plumbing for the user generated content endpoints: reading the binary upload envelope, storing files inside the data directory and serving them back.

    Every path segment that originates from a request is validated before it touches the filesystem, so a crafted id or file name cannot escape the data directory.
