    Ms2ex.Context.Accounts (MS2EX v0.1.0)

    Copy Markdown View Source

    Context module for account-related operations.

    This module provides functions for authentication, creation, retrieval, updating, and deletion of user accounts.

    authenticate(username, password)

    @spec authenticate(String.t(), String.t()) ::
  {:ok, Ms2ex.Schema.Account.t()} | {:error, :invalid_credentials}

    Authenticates a user with a username and password.

    Returns {:ok, account} if authentication is successful, or {:error, :invalid_credentials} if username doesn't exist or password is incorrect.

    Examples

    iex> authenticate("username", "password")
{:ok, %Schema.Account{}}

iex> authenticate("wrong_username", "password")
{:error, :invalid_credentials}
