    Summary

    Functions

    add(id, type, amount, opts \\ [])

    Adds mastery. The value never decreases and is capped at the type's maximum; the client is told the new value and grade changes feed the matching trophy/quest conditions.

    bulk_gather(character, recipe_id, amount)

    Harvests a recipe amount times without an interact object (the Smart Push bulk gather). Stops once the node's success rate has decayed to zero and returns how many harvests landed.

    bump_gathering_count(character_id, recipe_id)

    Bumps the harvest counter of a gathering recipe and persists it.

    call(id, msg)
    cast(id, msg)
    child_spec(init_arg)

    Returns a specification to start this module under a supervisor.

    claim_reward_box(character, reward_box_id)

    Claims the reward box of a mastery grade. The client addresses the box by mastery_type * 1000 + grade. Runs in the caller's process.

    craft(character, recipe_id)

    Crafts a mastery recipe: consumes its ingredients and meso cost, awards the mastery and hands out the crafted items. Runs in the caller's process.

    gather(character, object)

    Harvests a gathering node. Returns the updated character and whether the harvest succeeded; failures still consume the attempt.

    gathering_counts(character_id)

    Returns the character's harvest counters, keyed by recipe id.

    grade(id, type)

    Mastery grade (level) a type has reached.

    reset_gathering_counts(character_id)

    Drops the cached harvest counters after the daily reset cleared them.

    rewards_claimed(character_id)

    Claimed mastery grade reward boxes, keyed by reward box id.

    start(character)
    stop(id)
    value(id, type)

    Mastery value of a type.
