    consume_item_amount(character, item_id, amount)

    Consumes an amount across the character's carry stacks; returns {:error, :insufficient_amount} when the stacks cannot cover it.

    consume_item_amounts(character, consumables)

    Consumes each %{item_id, amount} pair from the carry stacks. Pairs the inventory cannot cover are skipped so callers can keep processing (the completion counter no longer matches the live inventory in that case).

    Moves an equipped item back to the inventory. Prefers preferred_slot while it is free, else the first open slot in the tab; the item's equip slot is cleared.
