    Ms2ex.Context.Mastery (MS2EX v0.1.0)

    Copy Markdown View Source

    Life skills: harvesting gathering nodes and crafting mastery recipes, plus claiming the reward boxes each mastery grade hands out.

    Mastery values, gathering counts and claimed rewards live on the character process (Managers.Character.Mastery); this module drives the gameplay flows around them.

    Summary

    Functions

    add(character, type, amount, opts \\ [])

    Adds mastery through the character process so the authoritative value is the one in memory.

    bulk_gather(character, recipe_id, amount)

    Harvests a recipe amount times without an interact object (the Smart Push bulk gather). Stops once the node's success rate has decayed to zero and returns how many harvests landed.

    claim_reward(character, reward_box_id)

    Claims the reward box of a mastery grade. The client addresses the box by mastery_type * 1000 + grade.

    craft(character, recipe_id)

    Crafts a mastery recipe: consumes its ingredients and meso cost, awards the mastery and hands out the crafted items.

    gather(character, object)

    Harvests a gathering node. Returns the updated character and whether the harvest succeeded; failures still consume the attempt.

    grade(character, type)

    Mastery grade (level) of a type.

    value(character, type)

    Mastery value of a type.
