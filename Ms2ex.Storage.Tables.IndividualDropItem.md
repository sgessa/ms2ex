# `Ms2ex.Storage.Tables.IndividualDropItem`
[🔗](https://github.com/sgessa/ms2ex/blob/main/lib/ms2ex/storage/table/individual_drop_item.ex#L1)

# `get`

Resolves an individual drop box id to its drop groups, keyed by group id.

# `has_entries?`

Whether the drop box exists with at least one drop group; a box without
entries cannot be opened (reference returns its inventory-fail error).
