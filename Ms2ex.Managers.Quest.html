    Ms2ex.Managers.Quest (MS2EX v0.1.0)

    Copy Markdown View Source

    GenServer to manage quest state for a character.

    This module handles quest state, progression tracking, condition checking, quest completion, and reward distribution.

    Summary

    Functions

    Abandons a quest for a character.

    Checks if a character can complete a specific quest.

    Checks if a character can start a specific quest.

    Returns a specification to start this module under a supervisor.

    complete(quest_id, character_id)

    Completes a quest for a character.

    dispatch(character_id, quest_id)

    Moves the character to a quest's dispatch destination (the "do you want to travel?" prompt from quest dialogues).

    expire_quests(character_id, quest_ids)

    Removes the given quests from the character (expiration sweep from the client) and drops their persisted rows.

    get_all_quests(character_id)

    Get all quests for a character, including both character-specific and account quests. Returns a tuple of {account_quests, character_quests}.

    get_available_quests(character_id, npc_id)

    Gets quests available from a specific NPC.

    get_quest(character_id, quest_id)

    Get a specific quest by ID.

    get_state(character_id)

    Gets the current state of the quest manager.

    go_to_npc(character_id, quest_id)

    Moves the character to a started quest's go-to-npc destination map.

    load_quests(session)

    Loads all quests for a character and sends to client.

    start(character, quest_metadata)

    Starts a new quest for a character.

    start_link(character_id)

    Starts a quest manager for a character.

    update_conditions(character_id, condition_type, counter \\ 1, target_string \\ "", target_long \\ 0, code_string \\ "", code_long \\ 0)

    Updates quest conditions based on character actions.

    update_tracking(character_id, quest_id, tracking)

    Updates tracking status for a quest.
